# 비율 차트 감시

`ratios.txt`의 비율 26개(A÷B)를 매일 장 마감 후 계산해서, 해석 문장과 분류별 표를 디스코드로 보냅니다. **한국 시각 평일 아침 07:15쯤** 도착합니다 (GitHub 사정으로 5~30분 늦을 수 있음).

## 디스코드 알림 모양

```
📊 비율 차트 해석 | 2026-10-15 마감
위험선호 종합: 🟢 위험선호  (16개 중 선호 12 · 회피 3 · 중립 1)
교차확인 (소비재·신용·시장폭): ✅ 모두 상승 → 위험선호가 넓고 건강함
⚠️ 다이버전스: SPY는 고점 -1.2%인데 RSP/SPY 하락 추세 → 상승이 좁아지는 경고
· 스타일: 성장·대형기술 주도
· 기술 내부: 반도체(AI 인프라) > 소프트웨어
· 경기: 확장 기대
· 채권: 장기채 약세 → 장기금리 상승 압력
최근 추세 전환: HYG/LQD 📈, IWM/QQQ 📉

· 위험선호
   비율          1W%    1M%    3M%  위치  설명
📈 XLY/XLP      +0.0   -0.9  +17.2    85  경기소비재 vs 필수소비재
📈 HYG/IEF      +1.0  +25.0  +20.7    97  하이일드 vs 국채 (신용)
...
(성장가치 · 시장폭 · 경기인플레 · 금리금융 · 원자재통화 표가 이어짐)
```

## 계산 방법

| 항목 | 방법 |
|---|---|
| 추세 📈 / ➖ / 📉 | 비율이 50일선 위이고 20일선 > 50일선이면 📈, 반대면 📉, 그 외 ➖ |
| 1W% · 1M% · 3M% | 비율의 1주·1개월·3개월 변화 |
| 위치 | 52주 범위 안에서 지금 비율의 위치 (0 = 최저, 100 = 최고) |
| `*` | 최근 1주 안에 추세가 바뀐 비율 |

## 자동 해석 문장

| 항목 | 내용 |
|---|---|
| 위험선호 종합 | 극성이 있는 비율 16개로 판정: 🟢 위험선호 / 🟡 혼조 / 🔴 위험회피 |
| 교차확인 | XLY/XLP, HYG/IEF, RSP/SPY가 같은 방향인지 (소비재·신용·시장폭) |
| 다이버전스 | SPY가 52주 고점 3% 이내인데 RSP/SPY·HYG/IEF·XLY/XLP 중 하락 추세가 있으면 ⚠️ |
| 주제별 | 스타일, 기술 내부, 시장폭, 경기, 인플레, 은행, 채권, 변동성(VVIX/VIX·SPX/VIX), 금·은·신흥국·비트코인 |
| 최근 추세 전환 | 1주 안에 방향이 바뀐 비율 |

## 설치 (새 저장소, 약 10분)

1. **디스코드**: 새 채널 생성 (예: `비율-차트`) → ⚙ → 연동 → 웹후크 → 새 웹후크 → 채널이 새 채널인지 확인 → **웹후크 URL 복사**
2. **GitHub**: New repository (Public, 이름 예: `ratio-watch`) → `ratio_watch.py`, `ratios.txt`, `requirements.txt`, `README.md` 업로드 → Commit
3. **Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` → zip 안의 같은 파일 내용을 붙여넣기 → Commit
4. **Settings → Secrets and variables → Actions → New repository secret**: Name `DISCORD_WEBHOOK_URL`, Secret에 1번 웹후크 주소
5. **Actions → Ratio Watch → Run workflow**로 테스트 (1~2분)

## 비율 추가·삭제

`ratios.txt`에 `분류, A/B, 극성, 설명` 형식으로 한 줄씩 적습니다.

| 극성 | 뜻 |
|---|---|
| 1 | 비율 상승 = 위험선호 |
| -1 | 비율 상승 = 위험회피 (예: TLT/SHY) |
| 0 | 위험선호 종합 점수에서 제외하고 표·주제 해석에만 사용 |

분류는 `위험선호, 성장가치, 시장폭, 경기인플레, 금리금융, 원자재통화` 중 하나를 씁니다. 티커는 야후 파이낸스 표기입니다 (예: 구리 선물 `HG=F`, 금 선물 `GC=F`). 지수는 `SPX`, `NDX`, `VIX`, `VVIX`, `VIX3M`, `DXY`로 적어도 자동 변환됩니다.
